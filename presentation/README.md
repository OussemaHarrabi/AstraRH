# AstraRH presentation

Open the deck locally:

```bash
python -m http.server 8090 --directory presentation
```

Then open <http://127.0.0.1:8090>.

## Controls

| Key | Action |
|---|---|
| `→`, `Space`, `PageDown` | next slide |
| `←`, `PageUp` | previous slide |
| `Home`, `End` | first or last slide |
| `F` | fullscreen |
| `N` | speaker notes |
